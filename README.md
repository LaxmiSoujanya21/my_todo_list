My To-Do List 🌷

A simple and stylish To-Do List web application built using HTML, CSS, and JavaScript.

Features

- Add new tasks
- Mark tasks as completed
- Delete individual tasks
- Clear all tasks
- Save tasks using Local Storage
- Display total and completed task counts
- Responsive design

Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

Live Demo
